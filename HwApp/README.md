# HwApp

Исходный код микросервисов интернет-магазина электроники.

## Сервисы

| Проект | Описание |
|---|---|
| [AuthService](./AuthService/README.md) | Регистрация, аутентификация, JWT и JWKS |
| [CustomerService](./CustomerService/README.md) | Профиль клиента и адресная книга |
| [CatalogService](./CatalogService/README.md) | Каталог товаров, бренды, категории и витрина |
| [WarehouseService](./WarehouseService/README.md) | Складские остатки, движения и резервы |
| [OrderService](./OrderService/README.md) | Заказы и оркестрация саги |
| [BillingService](./BillingService/README.md) | Счета, пополнения и платежи |
| [DeliveryService](./DeliveryService/README.md) | Зоны, слоты и резервы доставки |
| [NotificationService](./NotificationService/README.md) | Пользовательские уведомления |
