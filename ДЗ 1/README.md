# ДЗ 1 — Паттерны декомпозиции микросервисов

## Цель

Разделить архитектурную задачу **I'll Have the BLT** на микросервисы с учётом будущих изменений системы.

## Реализация

Для декомпозиции выбран паттерн **Decompose by Business Capability**. Границы сервисов определены по бизнес-возможностям интернет-заказов сети сэндвич-кафе.

В рамках работы подготовлены:

- пользовательские сценарии;
- описание микросервисов и их зон ответственности;
- синхронные и асинхронные контракты взаимодействия;
- контейнерная диаграмма C4 model.
