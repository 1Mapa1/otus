# Контракты взаимодействия микросервисов

## Синхронные контракты

| Потребитель | Поставщик | Контракт | Назначение |
|---|---|---|---|
| CustomerService | AuthService | идентификатор аккаунта из `AccountRegistered` / `GET /auth/me` | связать профиль с учётной записью |
| StoreService | CustomerService | `GET /customers/{customerId}` | проверить владельца и сотрудников точки |
| ProductsService | StoreService | `GET /stores/{storeId}` | проверить существование точки продаж |
| CartService | CustomerService | `GET /customers/{customerId}` | проверить владельца корзины |
| CartService | StoreService | `GET /stores/{storeId}` | проверить активность точки |
| CartService | ProductsService | `GET /products/{productId}?storeId=...` | получить цену и доступность позиции |
| PricingService | ProductsService | `POST /pricing/calculate` использует снимки позиций | рассчитать исходную стоимость |
| PricingService | StoreService | `GET /stores/{storeId}` | применить локальные акции |
| OrderService | CartService | `GET /carts/{cartId}` и `POST /carts/{cartId}/checkout` | получить и зафиксировать корзину |
| OrderService | PricingService | `POST /pricing/calculate` | зафиксировать итоговую стоимость |
| OrderService | PaymentService | `POST /payments` | создать оплату |
| OrderService | DeliveryService | команда создания доставки | создать доставку курьером |
| OrderService | ETAService | `POST /routes` | рассчитать маршрут и время самовывоза |
| DeliveryService | ETAService | `POST /routes` | рассчитать маршруты курьера |
| DeliveryService | PaymentService | `POST /payments/{id}/confirm` | подтвердить оплату при доставке |
| FeedbackService | OrderService | `GET /orders/{orderId}` | проверить завершение и владельца заказа |
| FeedbackService | StoreService | `GET /stores/{storeId}` | проверить точку продаж |

## Асинхронные контракты

| Издатель | Событие | Получатели | Назначение |
|---|---|---|---|
| AuthService | `AccountRegistered`, `AccountBlocked` | CustomerService | создать или заблокировать профиль |
| CustomerService | `CustomerContactsChanged`, `CustomerPreferencesChanged` | NotifyService | обновить локальную проекцию контактов |
| CartService | `CartCheckedOut` | AnalyticsService | учесть конверсию корзины |
| OrderService | `OrderCreated`, `OrderAccepted`, `OrderReady`, `OrderCancelled`, `OrderCompleted` | DeliveryService, FeedbackService, NotifyService, AnalyticsService | запустить связанные процессы и обновить проекции |
| PaymentService | `PaymentCompleted`, `PaymentFailed`, `PaymentRefunded` | OrderService, NotifyService, AnalyticsService | обновить состояние заказа и уведомить пользователя |
| DeliveryService | события назначения и этапов доставки | OrderService, NotifyService, AnalyticsService | синхронизировать статус заказа и доставки |
| FeedbackService | события создания отзывов | AnalyticsService | обновить показатели качества |

События содержат уникальный `eventId`, время создания, версию контракта и идентификатор бизнес-объекта. Обработчики должны быть идемпотентными.
