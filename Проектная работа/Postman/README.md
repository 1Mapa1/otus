# Postman-тесты

В каталоге находятся два независимых набора автотестов.

| Набор | Стенд | Назначение |
|---|---|---|
| [Main](Main/README.md) | `make install` | Полная проверка основного функционала всех микросервисов |
| [Observability](Observability/README.md) | `make install-demo` | Проверка Auth и Customer с последующим просмотром логов в Kibana и метрик в Grafana |

Каждый каталог содержит собственную коллекцию, окружение и подробную инструкцию по запуску.
