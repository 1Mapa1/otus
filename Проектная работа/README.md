# Выпускная проектная работа — интернет-магазин электроники

Микросервисная backend-платформа интернет-магазина электроники: регистрация пользователей, каталог и склад, оформление и оплата заказов, доставка и уведомления.

## Цель

Спроектировать и реализовать распределённую систему на основе микросервисной архитектуры с независимыми данными, синхронным и асинхронным взаимодействием, обработкой распределённых транзакций и средствами наблюдаемости.

## Что реализовано

- восемь микросервисов на ASP.NET Core;
- JWT-аутентификация и ролевая авторизация;
- PostgreSQL, Redis и Apache Kafka;
- оркестрация саги оформления заказа;
- идемпотентность команд и обработки сообщений;
- transactional outbox и inbox;
- API Gateway на Traefik;
- развёртывание в Kubernetes через Helm;
- метрики Prometheus и dashboard Grafana;
- централизованные логи в Elasticsearch и Kibana.
